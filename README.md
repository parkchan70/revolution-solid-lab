# 빙글빙글 회전체 실험실

중학교 1학년 수학 '입체도형 - 회전체' 단원용 수업 도구입니다. 평면도형을 회전축을 중심으로 1회전 시키는 과정을 3D 애니메이션으로 보여 주고, 만들어진 회전체를 평면으로 잘라 단면을 확인할 수 있습니다.

## 바로 쓰기
GitHub Pages 주소로 접속하면 설치 없이 사용할 수 있습니다. 컴퓨터, 태블릿, 휴대폰 브라우저에서 모두 열립니다.

## 기능
- 기본 도형 6가지: 직사각형→원기둥, 직각삼각형→원뿔, 사다리꼴→원뿔대, 반원→구, 삼각형→두 원뿔을 붙인 모양, 떨어진 직사각형→가운데가 뚫린 원기둥
- 직접 그리기: 모눈 위의 점을 찍어 나만의 평면도형 만들기 (0.5칸 단위)
- 회전 애니메이션: 0°부터 360°까지 회전하며 입체가 만들어지는 과정, 슬라이더로 각도 조절
- 3D 시점 바꾸기: 마우스나 손가락으로 끌어서 돌려 보기
- 단면 보기: 회전축을 포함하는 평면(선대칭도형), 회전축에 수직인 평면(원, 높이 조절)
- 회전체 이름, 만든 방법, 성질 설명 카드

## 참고
- 3D 그래픽은 Three.js(r128)를 사용합니다.
- HTML 파일 하나로 되어 있어 `index.html`을 내려받아 고쳐 쓸 수 있습니다.
